About this toolkit

All the Best Internet Utilities & Standalone Tools is a production subpage of CoreyMcDaniel.com. It gathers single-purpose webmaster, writer, developer, and everyday utilities that typically live across dozens of third-party sites.

The design goal is a neon workbench you can keep, fork, or host statically. Default processing is local. There is no account wall and no advertising pixel.

Network use is opt-in and disclosed on the DNS lookup page, which talks to Cloudflare DNS-over-HTTPS only after a button press.
