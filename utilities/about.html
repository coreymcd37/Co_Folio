About this toolkit

All the Best Internet Utilities & Standalone Tools is the flagship live demo in Co_Folio by Corey McDaniel. It gathers single-purpose webmaster, writer, developer, and everyday utilities that usually live across dozens of third-party sites.

The design goal is a neon workbench you can use immediately: focused tools, coherent chrome, and a privacy model you can read in plain language. Default processing is local. There is no account wall and no advertising pixel.

Network use is opt-in and disclosed on the DNS lookup page, which talks to Cloudflare DNS-over-HTTPS only after a button press.

When the custom domain is configured, this same toolkit will remain at /utilities/ on coreymcdaniel.com. Until then, the canonical demo lives on GitHub Pages.
