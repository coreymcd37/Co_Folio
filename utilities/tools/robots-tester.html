Robots.txt Tester

Test whether a path is allowed against pasted robots.txt rules.

This utility processes input in your browser. Files and text are not uploaded to CoreyMcDaniel.com. The DNS tool is the exception: it contacts Cloudflare DoH only after you press Resolve.

How it works

Test whether a path is allowed against pasted robots.txt rules. Output can be copied, printed, or downloaded from this page. Use the result as a starting point and verify anything that will ship to production.
