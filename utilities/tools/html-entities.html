Escape and unescape HTML entities.

This utility processes input in your browser. Files and text are not uploaded to CoreyMcDaniel.com. The DNS tool is the exception: it contacts Cloudflare DoH only after you press Resolve.

How it works

Escape and unescape HTML entities. Output can be copied, printed, or downloaded from this page. Use the result as a starting point and verify anything that will ship to production.
